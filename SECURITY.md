# Security policy

## Reporting a vulnerability

Please report a security problem privately, using GitHub's private vulnerability reporting: open the repository's Security tab and choose "Report a vulnerability".

Please do not put exploit details in a public issue. For a problem that is not sensitive (a false positive that hides a real defect, a wrong severity, a missing check), a normal issue is fine.

Include the Meerkat version (`meerkat --version`), what you ran, and what you expected. We aim to acknowledge a report within a few days.

## Supported versions

Only the latest `main` is supported. Fixes land there and are not back-ported.
